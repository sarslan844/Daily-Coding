# Daily Coding & CV Experiments

A collection of daily scripts focused on Computer Vision, deep learning model training, auto-annotation tools, and video processing utilities.

## Folder Structure & Scripts
- **Model Training & Fine-Tuning:** Scripts for training and fine-tuning YOLO, Artic, and custom models.
- **Data Annotation Pipelines:** Automated and semi-automated annotation tools (`inference.py`, `Yolo_Model.py`).
- **Video Preprocessing:** Frame extraction and video clipping tools (`video_frames.py`, `video_clipping.py`).
